Rules (replacing fix2 L-2 and L-3; tests and code refer to them by id):
- L-2 Text (display encoding; not reversible, a literal backslash is shown as is). Process each header value whole, and history/live text after splitting on LF. Scan left to right; at each position try, in this order:
  1. CSI: `(ESC [ | U+009B) [0-?]* [ -/]* [@-~]`;
  2. string: introduced by `ESC ]`, `ESC P`, `ESC X`, `ESC ^`, `ESC _` or the C1 forms U+009D, U+0090, U+0098, U+009E, U+009F, running through the first ST (`ESC \` or U+009C); for OSC (`ESC ]`, U+009D) BEL also terminates;
  3. other ESC: `ESC [ -/]* [0-~]`, tried only when the next character is none of `[ ] P X ^ _`.
  A complete match is removed whole. A start that does not complete before the end of the value/line is incomplete: its introducer (ESC or the C1 character) is kept as a character and the scan resumes at the next character, so the introducer is never reinterpreted. Remaining characters: those with `str.isprintable()` stay; LF and TAB become `\n` and `\t`; every other character becomes a fixed-width lowercase escape, `\xNN` up to U+00FF, `\uNNNN` up to U+FFFF, `\UNNNNNNNN` above. `planning.clean` is not this rule. Widths are measured in terminal cells (wide characters count 2).
- L-3 Header (supported layout). Home, provider, model and effort are separate named values from their resolution through layout; the turn and token counters stay integers. No field is ever reconstructed from a display string; L-2 and elision apply only after a field is selected. Exactly 4 rows, one field each, in this order: model + effort, provider, CODEX_HOME, usage. CODEX_HOME is cut by middle elision (start and end kept); model and provider by end elision. Usage: the full form "ходов N · токенов M" when it fits; otherwise the compact form "х N · т M" where a counter < 1000 is exact and a larger one is floored to one decimal with k/M/G/T (1000015 -> "1.0M", 10**12 -> "1.0T"); >= 10**15 shows "999T+". Counters are integers >= 0. The compact form fits in 20 cells for every value. The full CODEX_HOME stays reachable unshortened in Settings (not through the 256-char `summary`).
