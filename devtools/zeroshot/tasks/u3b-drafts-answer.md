- Answer draft -> the existing answer path. The answer draft identity is a dict (architect.py `tokens[milestone]`). Opening, on the worker: rebuild the original `Token` from it, call `resolve(token, exact=True)` first, then the read-only `Delivery.view(r)`; a mismatch is refused before any view is built (never join a newer attempt's view with the old token). The modal opens only if that EndView offers `answer`; an active attempt, a finished one, no attempt, or a missing/malformed identity give a clear refusal without `_end`/export. The modal is prefilled and editable; the draft's provenance is held apart from the current view through editing, and the send callback never swaps in a fresh token.
- Stale drafts are rejected without side effects. On send, the draft's token is re-checked with `resolve(exact=True)` on the worker before the existing answer path. A mismatch shows "черновик устарел: <the existing Changed reason>" ("план пересмотрен" / "начата другая попытка" / "попытка продвинулась", the last also covering a finished milestone), family `draft.stale`, and sends nothing. The refusal must not run `_end`/`Delivery.end` export: today `_acting` calls `_end` on a token mismatch, which can export a finished attempt, so the draft path needs its own Changed branch with no export; the typed-answer path stays as it is. The draft text stays copyable.
