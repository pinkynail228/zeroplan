Rules:
- R-1 Probe (parent R-1 mechanics; which roots is s5a3). `probe(roots, stat=os.stat, usage=shutil.disk_usage)`: `roots` is an ordered sequence of `(name, source)`; `source` is a str/PathLike or a zero-argument callable returning one. Per root: `value = source() if callable(source) else source`, then `path = os.path.abspath(os.fspath(value))`; its nearest existing ancestor is the path itself or the first parent for which `stat` succeeds, walking up only on FileNotFoundError/NotADirectoryError; the device is that stat's `st_dev`; free bytes are `usage(ancestor).free`. The two seams are the only filesystem calls: no `mkdir`, `Path.resolve`, `realpath`, `exists()`; nothing is created or written. Successful roots on one device form one `Probe(names, path, ancestor, device, free, error="")` (names in input order, path/ancestor of the first such root); `usage` is called once per device. Error Probe fields: `Probe(names=(name,), path=<abspath or "" if it was not computed>, ancestor=<the stat-succeeded ancestor or "">, device=<st_dev or None>, free=None, error=<class name>)`. If `usage` raises for a device, `usage` is not called again for that device: all successful-stat roots on it form one error Probe with their names in input order (path/ancestor/device of the first), free None, error the class name; roots probed later on that device join it.
- R-2 Thresholds (parent R-2). `GIB = 2**30`, `WARN_GIB = 15`. `threshold(environ=None)` reads `ZPLAN_MIN_FREE_GB` from `environ` (default: `os.environ` at call time). Unset gives 5. A value that fully matches `[0-9]+` (ASCII digits only) with int value > 0 gives that int: leading zeros allowed (`0000000005` is 5, round R2), no upper cap; the conversion never hits Python's int string-digit limit (strip leading zeros and convert without `int(str)` overflow, e.g. chunked), so 5000-digit values are valid. Anything else (empty, whitespace, sign, `0`/`000`, fraction, exponent, nan/inf, non-ASCII digits such as `５` or `٥`, words) gives None = invalid configuration.
- R-3 Classify. `classify(probes, block_gib)` returns a tuple of frozen `Verdict(severity, kind, names, path, ancestor, free, threshold, error)`. With `block_gib` None: exactly one leading `Verdict("block", "invalid_config", ...)` (no path), and the probes are still classified against the default 5 so free space stays visible. Per probe: error gives `("warn", "error")`; else `free < block_gib*GIB` gives `("block", "low")`; else `free < WARN_GIB*GIB` gives `("warn", "low")`; else `("ok", "ok")`. Block is evaluated first; equality to a threshold is not below it. With an override above 15 there is no warn band.
- R-4 Refusal (pure). `refusal(verdicts)` returns the first `block` verdict (invalid_config precedes low by R-3 order), else None. A root error never hides another device's block (parent R-5).
- R-5 Errors (parent R-5; S-3). Exactly these become that root's error Probe: OSError (incl. PermissionError), RuntimeError and ValueError (e.g. NUL in a path) raised by the source callable, `abspath`, `stat` or `usage`. `error` is the exception class name only (no message, no errno text). The remaining roots are still probed. No bare `except` or `except Exception`.
- R-6 Pure module: raises no family (catalog entries `disk.low`/`disk.invalid_config`/`readiness.disk` are s5a3's), imports none of setup/runs/planning/delivery/cli/tui, prints and logs nothing; no caller is wired (s5a3).

Acceptance (the `stat`/`usage` seams are fakes scripted per path with st_dev and free bytes; a temp directory is used only for the no-create check; the machine's real free space is never read):
- A-2t (parent A-2, threshold half): default block 5: free 5 GiB−1 gives block; 5 GiB warn; 15 GiB−1 warn; 15 GiB and 15 GiB+1 ok. Override 3 (below 15): 3 GiB−1 block; 3 GiB warn. Override 20 (above 15): 20 GiB−1 block; 20 GiB and 20 GiB+1 ok. Long values: 5000 nonzero ASCII digits gives that exact int (no ValueError); 5000 leading zeros followed by `5` gives 5. Error Probe: fields as in R-1 for a failing source callable, stat and usage; after a `usage` error a second root on the same device joins that error Probe and `usage` is called once.
- A-3 (parent A-3): a root three levels below its nearest existing ancestor resolves to that ancestor, and the temp tree is unchanged (same listing before/after); two roots on one device give one Probe naming both and one `usage` call; two devices give two; a PermissionError from `stat` for one root (and, separately, from a source callable) plus another device at 1 GiB: `refusal` is that low block and the failing root is a warn verdict carrying the class name.
